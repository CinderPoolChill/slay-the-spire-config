## 🧩 About

**Slay the Spire Config** is a comprehensive configuration tool for Slay the Spire featuring an overlay menu, deck editor, relic unlocker, gold and HP modifiers, ascension level selector, and card reward manipulator.

Based on popular mods like **ModTheSpire**, **BaseMod**, and **StSLib**.

---

## ✨ Features

### 🎮 Core Config
- Overlay Menu — toggle with hotkey, adjust settings in real time
- Deck Editor — add or remove any card from your deck
- Relic Unlocker — unlock all relics and relics+ for all characters
- Gold Modifier — set gold amount to any value
- HP Modifier — set max HP and current HP

### 🎨 Cosmetics & Unlocks
- Ascension Level Selector — set ascension level from 1 to 20
- Card Reward Manipulator — choose any card as reward
- Unlock All Characters — unlock Silent, Defect, Watcher
- Neow Bonus Selector — choose any starting bonus

### 🏋️ Practice & Training
- Infinite Energy — never run out of energy
- Instant Win — defeat current enemy instantly
- Draw Any Card — draw specific card from draw pile
- Save State — save and load game state
